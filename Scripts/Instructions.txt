NPCDialogue.cs - updated to be NPC_try_2
	This script will be attached to each NPC character - manages dialogue and sends dialogue to dialogue manager. Each time you click the mouse, whether or not on the object, it will go to the next line, until it runs out of lines
- give the dialogue variable a reference to one dialogue object for that character
- set shouldRepeatDialogue to true if you want that npc to repeat a line
- set currDialogue if you want the npc to start at dialogue after the first sentence/line/etc...
- Set EndDialogueAfter to the indice of the dialogue before the dialogue that gets repeated
- provide a reference to the character so that the "Can move" variable in its code can be set
Update: also stores its dialogue in the class, and then will send it to dialogue manager
Update Update: if the character is a background character, check that box, and then it will randomly play dialogue lines that it has (each line must have END as it's last line)

DialogueManager.cs (was made for the fall game jam, not by me)
-Attach this script to a UI GameObject that has a TextMeshProUGUI component, which is used to display dialogue text.
-Make sure there's only one DialogueManager in the scene by setting it as a singleton in the Awake method.
-Use ShowDialogue to display a string of text in the dialogue UI.
-Use HideDialogue to hide the dialogue UI when the interaction is complete.
(I made one change so we could make it visible or not when you first start the game)
-To make it so that it's not on by default, just uncheck the OnByDefault box
